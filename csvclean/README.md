# csvclean — CSV 清洗与体检

问卷平台、Excel、数据库导出的 CSV，先在本地体检一遍再进 SPSS / R / Python。纯浏览器运行，数据不上传。

## 功能

### 自动检测

- **分隔符**：逗号 / 分号 / Tab / 竖线，按行内频次与一致性判定
- **编码**：UTF-8（严格模式）→ 失败自动回退 GB18030（问卷平台、老版 Excel 导出常见），BOM 自动剥离
- **列类型**：数字 / 日期 / 文本 / 全空

### 问题报告（只报告，不擅自改）

- 各行列数不齐（混合分隔符、漏字段的信号）
- 引号不闭合、字段中间的杂散引号
- 重复列名、全空列
- **数字列混入文本**：某列基本是数字但个别行不是（乱码/单位/千分位的信号），列出具体行号
- 零宽/隐形字符、全角字母数字、首尾空格的单元格计数

### 清洗动作（全部勾选制）

去首尾空白与隐形字符 · 删空行 · 删重复行 · 全角转半角 · 中文引号规范化——做了什么、改了多少处，逐项列出。清洗结果可复制或下载 `-clean.csv`。

## 使用

打开 [csvclean](https://icgma.github.io/newsroom-kit/csvclean/)，拖入文件或粘贴文本。

## LLM 接口

```
GET https://icgma.github.io/newsroom-kit/csvclean/?input=<URL编码CSV>#json
```

返回分隔符、清洗动作、行列数、列类型与问题清单、清洗后输出。
