# redact — 访谈稿匿名化

自动识别并遮盖中文文本中的人名、机构名、地名、身份证号、手机号、邮箱。**每一处替换都可以逐项复核撤销**，替换映射表可导出为 CSV，满足 IRB / 伦理审查对可追溯匿名化的要求。

## 功能

### 内置检测（正则 + 词典，本机运行）

| 类型 | 原理 | 示例 |
|------|------|------|
| 人名 | 百家姓 + 上下文启发式（敬语、引语动词、并列语境） | 受访者张三表示 → 【姓名1】 |
| 机构名 | 后缀词表（大学/公司/研究所…），自动剥离"他在"等前缀 | 北京大学 → 【机构1】 |
| 地名 | 行政区划词表（省/市/区 300+） | 朝阳区 → 【地点1】 |
| 身份证号 | 18 位 + 校验位验证 | 110101… → 【证件1】 |
| 手机号 / 邮箱 | 正则 | 138… → 【电话1】 |

人名识别策略：**宁可漏判、不可错杀**——配合逐项复核，把最终决定权留给研究者。

### 逐项复核（新）

- 每处替换在清单中列出：原文、替换、类型、来源、出现次数
- 取消勾选即还原该项，其余序号自动重排
- 导出的 CSV 只包含当前勾选项

### 自定义规则与 LLM

- 自定义正则规则（项目编号、日期等），保存在本机
- 可选 LLM 命名实体识别（自备 API key，浏览器直连你配置的端点，LLM 结果优先）

## 隐私

除显式启用 LLM（发送至你配置的 API 端点）外，全部在本机浏览器完成。

## LLM 接口

```
https://icgma.github.io/newsroom-kit/redact/?input=<URL编码文本>#json
```

详见 [SKILL.md](SKILL.md)。

